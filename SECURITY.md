# Security

Carrie On can resume explicitly enrolled chats with their existing Codex permissions. Treat access to the logged-in macOS account as access to its queue and instructions. The HTTP interface is loopback-only and rejects foreign origins; the desktop adapter checks socket ownership and rejects unsupported protocol versions.

Report ordinary defects through GitHub Issues. For a vulnerability that could expose chat data or trigger unauthorized work, contact the maintainer privately at nickcorin@gmail.com. Include affected versions and a minimal reproduction with synthetic data. Do not post credentials, queue contents, or private chat logs publicly.

Security fixes target the latest release. Releases currently use ad-hoc code signing, not Developer ID signing or notarization. Compare the downloaded archive against its published SHA-256 checksum; this detects corruption but does not independently authenticate the publisher.
