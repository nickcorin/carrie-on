# Security

Carrie On can resume queued chats with their existing Codex permissions. Anyone with access to your logged-in macOS account can access its queue and instructions.

Report ordinary defects through [GitHub Issues](https://github.com/nickcorin/carrie-on/issues). For a vulnerability that could expose chat data or trigger unauthorized work, contact the maintainer privately at nickcorin@gmail.com. Include affected versions and a minimal reproduction with synthetic data. Do not post credentials, queue contents, or private chat logs publicly.

Security fixes target the latest release. Releases are ad-hoc signed and are not notarized. Published checksums detect damaged downloads but do not independently authenticate the publisher.
