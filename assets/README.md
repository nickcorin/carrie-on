# Carrie On artwork

The C flows into a forward arrow to express continuation. The app icon uses ivory on a warm coral tile; the menu bar uses only the silhouette.

- `app-icon.png`: full-resolution master with alpha, created with built-in ImageGen.
- `CarrieOn.icns`: macOS icon family, packaged by `python3 build_icons.py` with Apple's `sips` and `iconutil`.
- `../web/app-icon.png`: 128-pixel dashboard and favicon asset, generated by the same command.
- `tray-icon.svg`: editable monochrome mark. The app draws the corresponding geometry in `../menubar/Brand.swift` as an 18-point AppKit template image, adapting to menu-bar appearance and display scale.
